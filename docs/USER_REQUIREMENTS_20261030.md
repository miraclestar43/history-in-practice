## 阅读时间与英文质量

- **中文完整阅读约十分钟；英文完整阅读也各约十分钟。不是两种语言合计十分钟。** 用户可只读一种，也可对照阅读两版。
- 初稿暂以中文约 2,800–3,600 字、英文约 1,800–2,200 words 为松的参考；不是硬性字数验收，最终按读者各语言的实际阅读体验校准，不增加无用句子凑长度。
- 阅读时间覆盖故事、分析、简短现实应用、边界、开放问题与示例解答；继续点开外部来源的时间不包括在内。
- 两版是同一篇文章的对应表达，事实、数字、立场、保留条件与来源一致。英文应像自然写成的历史文章，允许重组句法、调整节奏、解释中文文化背景，避免中式英语、逐字翻译和空泛套话；不能添加无史料支持的细节来本地化。
- 两个语言版本分别估算阅读时间。自然译文时间略有差异时，报告真实估算并据反馈调整，不强制字数比例或信息不对称。
- 每篇保留有趣叙事、开放问题、含真实权衡的示例思路、适用边界、本篇出处与带说明的延伸阅读。
