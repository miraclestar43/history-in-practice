# 原文精选: the default form of the column (from 2026-11-02)

**Decision.** The owner approved the two samples and made 原文精选 the default for new content.
- **An issue is:** a short introduction, the author's own text as the body, notes (folded on the web), 读后想一想 with one folded 一个参考角度, and a faithful AI translation into the other language. Each part is labelled.
- **Not generated by default:** long rewritten stories, application scenarios, model answers.
- **Story inventory:** kept as backup. It is not rewritten, and 胡适 is not redone.

## The chain

`src/history_in_practice/excerpt.py`, prompts `excerpt_*.md`; every model call is Claude Opus via the Claude Code CLI.

1. **select:** the model gets a numbered window of a library book (a chapter unit). It returns a paragraph range, any whole-paragraph omissions (〔中略〕), an editor's title, why it chose the passage and why it stands alone. It never returns text.
2. **extract** (program): the paragraphs are taken from the saved book file, and its location is kept. Chapter-heading lines are not part of the text.
3. **guide:** dek, a short introduction, a name list, notes (each with a Chinese entry word and the original term, which must appear in its paragraph), read-on, and episode metadata for dedupe.
4. **translate:** one paragraph per paragraph, using the name list. Unverified names are marked as provisional transliterations, with the original spelling once.
5. **review** (twice): selection and omissions, missing context, references, unsupported claims in the editor's text, translation fidelity. Fixes may change the editor's text or translation paragraphs, never the original.
6. **reflect:** one or two questions and one reference angle. These are editor's content, grounded in details of the text, with stated limits and no "standard answer". A review checks only these fields (basis, attribution, language).
7. **checks** (program):
   - every displayed original paragraph equals the source paragraph and is in the source cache;
   - omissions are marked;
   - the translation is aligned;
   - notes are anchored;
   - display pieces join back exactly;
   - no reader-facing editor text cites paragraph numbers.

**Display.**
- A Chinese **translation** of a long paragraph is shown in sentence-boundary pieces. The pieces join back to the paragraph exactly, so the paragraph stays the unit of correspondence.
- A Chinese **original** keeps the author's paragraphing.
- Long quotes that continue across pieces reopen with “, for display only.

## Into inventory, schedule, site, email, search

- **Admission** (`hip excerpt-admit PATH`, or automatic in the nightly job):
  - the record is re-verified on the machine: book file hash, text equality, checks, no open issue, a model reported for every call, rights public domain or licensed;
  - an episode (people + passage span) is registered for dedupe;
  - the edition becomes `checked` with an `excerpt-editor:` approval.
- **Re-verification at every use:** eligibility, scheduling and every recipient's send gate re-verify through `final_edit.admitted_file_problems`. The send gate compares the archived copy's body with the admitted one.
- **Mix:** within the group a slot wants (China / elsewhere), admitted 原文精选 come before stories. `hip plan --pin ID ... --commit` records an owner-authorized order.
- **Site and search:**
  - the page renders `kind: excerpt` with the byline, labels, paired view, folded notes and reference angle;
  - internal records (review, calls, selection, `admitted_from`) never reach the public JSON;
  - site verification recomputes the excerpt's hash;
  - the search index includes excerpts (names in both scripts, book titles, the text).
- **Email:** title → [在网页阅读] [Read in English] → dek → introduction → the text (labelled 原文 / AI 译文) → notes → questions with a link to the reference angle on the web page → read-on. Then the other language in full. No folding, no script.
- **Nightly** (`hip-prepare`, unchanged timer): with `editions.default = excerpt`:
  - it keeps about 6 admitted 原文精选 ready, at most 2 chain runs a night;
  - it uses public-domain books only, Chinese originals first, in the categories the mix needs most;
  - every tried unit is logged (`config/excerpts/attempts.jsonl` + `data/excerpts/attempts.jsonl`);
  - a clean result is admitted, and anything else stays a record;
  - rewritten-story supply, drafting and final editing are off.

## Books for public excerpts

Public domain, each checked for the specific edition used:
- **Chinese originals:**
  - 鲁迅《朝花夕拾》:《范爱农》,《琐记》;
  - 刘鹗《老残游记》, 20 回;
  - 沈复《浮生六记》, 卷一–四;
  - 梁启超《李鸿章传》.

  The Chinese texts come from zh.wikisource at pinned revisions, with markup removed and OpenCC tw2s for simplified characters (characters only).
- **English originals:** 容闳 *My Life in China and America* (1909), Mackay (1841).

In-copyright books stay available for choosing topics and internal reading, but not for long public excerpts.
